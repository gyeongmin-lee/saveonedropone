# Product Brief Distillate: Save One Drop One

## 핵심 컨텍스트

- **포맷 원형**: 한국 "이상형 월드컵" — 1v1 토너먼트 방식으로 취향을 탐색하는 인터랙티브 콘텐츠. 한국에서 스트리밍 문화와 결합해 수년간 검증된 포맷.
- **서구권 포맷명**: "Save One Drop One" — 이미 K-팝 팬덤 커뮤니티(Quotev, uQuiz, r/kpop)에서 자생적으로 쓰이고 있음. 신규 시장 개척이 아니라 검증된 수요에 전용 플랫폼 제공.
- **핵심 포지셔닝**: 스트리머-퍼스트 토너먼트 플랫폼. 스트리머에게는 "콘텐츠 고갈 해결 도구", 시청자에게는 "방송 후 직접 플레이하고 공유하는 경험".
- **개발 체제**: 1인 개발(GM). 개발자 친구들의 피드백 지원 가능. 외부 투자자 없음(현재).

---

## 초기 투자 논리 / Wedge

- **핵심 논리**: 브라켓 기능이 아니라 "방송 가능한 취향 논쟁 포맷의 패키징". TierMaker/BracketFights는 도구이고, Save One Drop One은 스트리머가 바로 방송에 올릴 수 있는 콘텐츠 단위.
- **초기 beachhead**: K-팝과 애니 우선. bias/최애/캐릭터 순위/커플링/세대별 논쟁처럼 1v1 선택 포맷과 맞는 문화적 행동이 이미 강함. 게임·스포츠는 확장 카테고리로 검증.
- **방어 논리**: 단일 기능은 복제 가능하지만, OBS 레이아웃 + 결과 이미지 + 비교 화면 + UGC + SEO 페이지가 하나의 루프로 연결되면 콘텐츠 그래프가 됨.
- **초기 검증 질문**: (1) 스트리머가 2회 이상 반복 사용하나? (2) 한 방송이 의미 있는 시청자 플레이 세션을 파생시키나? (3) 결과 공유와 비교 화면이 재방문을 만드나?
- **수익화 관점**: 광고, premium creator tools, 브랜드/event 브라켓, rev-share는 이 반복/바이럴 루프 검증 이후 트래픽 위에 얹는 레이어.

## 타겟 사용자 상세

**1차: 미드티어 스트리머 (ICP)**
- Twitch/YouTube, 구독자 10K~500K
- **핵심 식별 기준**: 현재 TierMaker를 방송에 활용하는 스트리머 — 이미 니즈가 증명된 사람들
- 콘텐츠 아이디어 고갈이 가장 큰 고통. "켜면 2~3시간이 채워지는 도구"가 이상.
- 도구 전환 비용이 낮음 — 채팅 반응 하나로 결정

**2차: 팬덤 시청자**
- 게임·애니·K-팝·스포츠 팬
- 스트리머 방송 후 "나도 해보고 싶다"는 욕구에서 유입
- Reddit, X(트위터), Discord에 결과 공유 → 2차 트래픽 생성

**3차: 팬덤 커뮤니티**
- r/kpop (200만+), 애니·게임 서브레딧
- 스트리머 없이도 독립적으로 브라켓 콘텐츠를 소비하는 층

## 사용자별 핵심 Job-to-be-Done

- **스트리머**: "오늘 방송할 콘텐츠를 바로 실행하고 싶다" → 방송-ready bracket pack 필요. 제품 객체는 큐레이션 브라켓, 썸네일, 제목, 예상 진행 시간, OBS 레이아웃, 공유 링크. 성공 기준은 10분 이내 방송 투입.
- **시청자**: "스트리머/친구와 내 취향 차이를 보여주고 싶다" → 개인 결과 페이지, 결과 이미지, 비교 링크, side-by-side 결과 화면 필요. 비교 화면은 바이럴 감정 훅.
- **UGC 제작자**: "내 팬덤의 대표 브라켓을 만들고 퍼뜨리고 싶다" → attribution, editability, discoverability 필요. 제작자명, 공개 브라켓 페이지, 카테고리, 수정 기능, 공유 메타데이터 포함.
- **스트리머 모더레이터/커뮤니티 관리자**: "방송에 올려도 안전한 콘텐츠인지 확인하고 싶다" → curated badge, preview mode, report/takedown, 공개/비공개 상태 필요. 오픈 UGC와 방송-safe 큐레이션 구분 중요.

---

## 핵심 제품 객체: Bracket Pack

- MVP의 기본 단위는 단순 브라켓이 아니라 **Bracket Pack**: 스트리머가 바로 방송에 쓰고, 시청자가 방송 후 같은 경험을 재생산할 수 있는 콘텐츠 패키지.
- 최소 구성: 제목, 카테고리, 썸네일/대표 이미지, 참가 항목 목록, 예상 진행 시간, OBS-friendly 플레이 레이아웃, 공개 브라켓 페이지, 결과 페이지, 결과 이미지 내보내기, 비교 링크, 공유 메타데이터.
- 유형: **Curated Pack**(플랫폼 선별, 방송-safe 기준) / **UGC Pack**(사용자 생성, 공개 인덱싱 전 최소 품질·정책 기준 적용).

## 경쟁사 인텔리전스

**BracketFights**
- 브라켓 포맷 있음, 방송 UI 없음, UGC 없음, 바이럴 루프 없음
- 유틸리티 도구 수준 — 커뮤니티·리텐션 메커니즘 전무
- 위협: 자금력 있으면 OBS 지원·공유 기능을 몇 주 안에 복제 가능

**TierMaker**
- 월 107만 트래픽, 강한 UGC/SEO 생태계
- 티어리스트 포맷 (토너먼트 아님) — 스트리머들이 임시방편으로 사용 중
- 광고·마케팅 없이 5개월 만에 15만 세션 달성 (UGC SEO 플라이휠 증거)

**PIKU (한국)**
- 한국 이상형 월드컵 선도 플랫폼
- 실측치: DAU ~4,200 / 일일 PV ~15,600 → **3.96 PV/방문자** (광고 모델 핵심 가정 검증)
- 영어 미지원, 스트리머 도구 없음, AI 기능 없음

**Challonge / StreamAlive / Streamlabs Poll**
- 실제 경쟁 토너먼트 관리 또는 단발성 투표 — 엔터테인먼트·취향 발견 목적 아님

## 기술 컨텍스트 & 제약

- **플랫폼**: 웹 우선. 앱은 추후 — Capacitor(웹 래핑) 또는 React Native(신규 개발) 검토 중, 미확정
- **OBS 최적화**: Twitch Extensions 방식으로 방송 중 라이브 폴 연동 필요 (스트리머 선택 시 시청자 채팅 투표 연동)
- **UGC 아키텍처 요건**: 사용자 생성 브라켓 각각이 독립 SEO 페이지로 인덱싱 (TierMaker 모델)
- **결과 내보내기**: 브라켓 트리 이미지 생성 → Twitter/Reddit/Discord 공유 최적화
- **비교 화면**: 두 사용자 결과를 나란히 보여주는 뷰 → "You're Wrong" 루프의 핵심 UX

## MVP 범위 확정

**포함 (v1)**
- 방송-ready 브라켓 팩 100+ (K-팝·애니 우선, 게임·스포츠 확장 검증): 제목, 썸네일, 예상 진행 시간, OBS 레이아웃, 공유 링크 포함
- 1v1 토너먼트 플레이 UI (방송 최적화, 모바일 대응)
- OBS 브라우저 소스 호환 방송 레이아웃
- 결과 브라켓 트리 이미지 내보내기 (SNS 공유)
- UGC 브라켓 생성 — **핵심 기능, v1 포함 확정** (스켑틱의 v2 이연 제안을 GM이 거절)
- Bracket Pack preview mode 및 curated/UGC 구분 표시
- 최소 UGC 운영 기능: 공개/비공개 상태, 신고, 관리자 takedown
- 기본 광고 슬롯 (결과 화면)
- 결과 비교 화면 (두 브라켓 나란히)

**제외 (MVP 이후)**
- AI Auto-Generate (주제 → 브라켓 자동 생성)
- AI 패널 (선택 딜레마 시 AI 편들기)
- AI 배틀 시뮬레이션 (파이널 두 대상 내러티브 대결)
- 네이티브 앱
- 크리에이터 애널리틱스 대시보드
- B2B 브랜드 브라켓 유료 판매
- 크리에이터 수익화(rev-share) — 탐색 예정, 미확정

## 수익 모델 세부

- **광고 (메인)**: 결과 화면 광고 슬롯. 세션당 ~4 PV × 미국 엔터 CPM $3~11. 수익은 규모 의존적.
- **리스크**: 게이밍/스트리밍 오디언스의 광고 차단기 사용률이 높음 (~40%+). 실제 수익은 이론치보다 낮을 수 있음.
- **중장기**: 크리에이터 프리미엄 구독 (AI 기능, 고급 분석 등)
- **탐색 중**: 크리에이터 rev-share — 스트리머가 자신의 브라켓 광고 수익 일부 수취. 채택 동기를 편의에서 경제적 인센티브로 격상시킬 수 있음. 미확정.

## GTM 전략 (초기)

- **K-팝·애니 중심 직접 DM**: TierMaker 또는 유사 랭킹 콘텐츠를 이미 방송에 활용하는 K-팝·애니 스트리머 우선. 메시지는 "새 도구"가 아니라 "오늘 바로 돌릴 수 있는 방송-ready bracket pack".
- **Reddit/Discord 공략**: K-팝·애니 서브레딧과 팬 Discord에 초기 Bracket Pack 배포. r/Twitch/r/StreamersConnect는 스트리머 획득 보조 채널.
- **Twitch Extensions 등록**: 라이브 폴 연동은 공식 채널로 추진하되, v1 출시는 OBS 브라우저 소스만으로 가능한 워크플로우 기준.

## 성공 기준

**단기 (0~6개월)**
- TierMaker 또는 유사 랭킹 콘텐츠 사용 스트리머 3명 이상이 2회 이상 반복 사용
- 스트리머가 Bracket Pack을 선택해 10분 이내 OBS 방송에 올릴 수 있음
- 단일 스트리머 방송에서 파생된 시청자 플레이 세션 1,000회 이상
- 초기 K-팝·애니 Bracket Pack 중 10개 이상이 방송 또는 커뮤니티 공유를 통해 의미 있는 플레이 세션 생성

**중기 (6~12개월)**
- 월 세션 50만 이상
- UGC 브라켓 500개 이상 누적

## 바이럴 루프 메커니즘

```
스트리머 방송 (128강, 2~3시간)
  → 시청자 채팅 참여 (Twitch Extension 투표)
  → 방송 후 시청자 개인 플레이 (스트리머 링크)
  → 결과 이미지 SNS 공유
  → 비교 화면 ("나와 달라" → 재플레이)
  → UGC 브라켓 생성
  → SEO 인덱싱 → 신규 유저 유입
```

K-factor 가설: 결과 공유자의 20%가 1회 이상 재방문 유도 시 바이럴 계수 1.0 초과. 검증 필요.

## 핵심 리스크와 완화 전략

- **반복 사용 검증**: 가장 큰 리스크는 제품 구현보다 스트리머의 정기 사용 루프 검증. MVP는 단순 브라켓 생성기가 아니라 썸네일·제목·예상 진행 시간·OBS 레이아웃을 포함한 "방송-ready 콘텐츠 패키지"여야 함.
- **스트리머 전환**: TierMaker 습관을 이기려면 1회 체험보다 2회 이상 반복 사용을 성공 기준에 포함해야 함.
- **Twitch Extension 의존**: 개발·심사·연동 지연 가능성. v1은 OBS 브라우저 소스만으로 방송 가능한 워크플로우를 확보하고, Twitch Extension 라이브 폴은 v1.5로 병렬 추진하는 안이 강함.
- **UGC/IP/모더레이션**: 이미지 저작권, NSFW, 저품질 중복 브라켓이 SEO 플라이휠을 오염시킬 수 있음. 신고, 관리자 takedown, 공개/비공개, 카테고리 분류, 중복 기준을 MVP 운영 요구사항에 포함 필요.
- **SEO 품질**: UGC 수량만으로는 부족. 공개 브라켓 페이지는 고유 title/description, category taxonomy, Open Graph 이미지, 결과 공유 URL, canonical URL 필요.
- **수익화 타이밍**: 초기 6개월은 광고 매출보다 반복 사용, 파생 플레이 세션, 공유율, UGC 생성률을 우선 지표로 봐야 함.

## 열린 질문 (PRD 단계에서 결정 필요)

- **Twitch Extensions 개발 복잡도**: 라이브 폴 연동을 MVP에 포함할지, 기본 OBS 브라우저 소스만 먼저 지원할지
- **UGC 콘텐츠 모더레이션**: 오픈 UGC 시 NSFW/IP 남용 대응 최소 기준 — 신고 플래그만? 검토 큐?
- **이미지 저작권 처리**: K-팝 아이돌·애니 캐릭터·스포츠 선수 이미지의 큐레이션 브라켓 법적 근거 (공정사용 vs 라이선싱 vs 팬아트)
- **브라켓 크기 옵션**: 고정 128강인지, 4/8/16/32/64/128 선택 가능인지
- **계정/인증**: 결과 저장·UGC 생성에 계정 필요 여부, 소셜 로그인 지원 범위
