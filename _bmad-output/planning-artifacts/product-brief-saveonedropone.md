# Product Brief: Save One Drop One

## 요약 (Executive Summary)

한국 인터넷은 글로벌 콘텐츠 포맷의 증류소였다. 먹방은 ASMR이 됐고, 웹툰은 Webtoon이 됐으며, 리액션 콘텐츠는 YouTube 메가 장르가 됐다. 다음 차례는 "이상형 월드컵"이다.

1v1 토너먼트 방식으로 자신의 취향을 찾아가는 이 포맷은 한국 스트리밍 문화에서 수년간 검증됐다. 스트리머 한 명이 128강을 돌리면 2~3시간의 방송이 자동으로 채워지고, 시청자는 채팅으로 참여하며, 결과 이미지는 SNS에 퍼진다. **Save One Drop One**은 이 포맷의 서구권 수출판이다.

광고 수익 구조는 이 포맷이 가진 구조적 우위에서 나온다. 일반 콘텐츠 사이트의 세션당 PV가 1.2 수준인 데 반해, 라운드마다 페이지가 전환되는 이 포맷은 한국 유사 플랫폼 실측치 기준 ~4 PV/세션을 기록한다 — 같은 트래픽에서 3배 이상의 광고 노출이 발생한다는 의미다. 여기에 IP 홀더의 브랜드 브라켓 유료 게재, 크리에이터 프리미엄 구독이 추가 수익원이 된다.

---

## 문제 (The Problem)

미드티어 스트리머의 가장 큰 고민은 콘텐츠 고갈이다. 매주 방송 주제를 새로 짜야 하고, 시청자를 붙잡을 인터랙션을 만들어야 한다. 이상적인 도구는 "켜면 2~3시간 방송이 자동으로 채워지는 것"이다.

현재 서구권 스트리머들은 이 공백을 TierMaker로 메우고 있다. TierMaker는 티어리스트 포맷이고 토너먼트가 아니다. BracketFights는 브라켓 포맷을 제공하지만 방송 UI가 없고, 결과 공유 기능이 미약하며, 커뮤니티가 없어 브라켓 발견 자체가 어렵다. 둘 다 스트리머를 위해 설계된 도구가 아니다.

시청자 입장에서도 문제는 같다. 방송이 끝난 뒤 직접 해보고 싶어도 갈 곳이 없다. 결과를 공유하고 싶어도 마땅한 형식이 없다. "나는 이렇게 골랐는데 너는?"이라는 자연스러운 바이럴 루프가 현재 어떤 서구권 플랫폼에도 없다.

---

## 솔루션 (The Solution)

Save One Drop One은 **스트리머-퍼스트 토너먼트 플랫폼**이다.

스트리머는 카테고리 브라켓(K-팝 아이돌, 애니 캐릭터, 스포츠 선수, 게임 캐릭터 등) 라이브러리에서 골라 방송을 바로 시작한다. 방송 UI는 OBS 브라우저 소스에 최적화되어 있고, 선택지는 크고 선명하며, 채팅 반응에 맞게 설계됐다.

시청자는 스트리머 방송을 보고 나서 자신의 링크를 받아 직접 플레이한다. 결과는 브라켓 트리 이미지로 내보내 SNS에 공유할 수 있다. 다른 사람의 결과 링크를 열면 두 브라켓이 나란히 비교되는 화면이 뜨고, 차이가 보이는 순간 재플레이 욕구가 생긴다 — "You're Wrong" 루프가 트래픽을 다시 끌어당긴다.

사용자들이 브라켓을 직접 만들어 올리면 UGC 라이브러리가 쌓이고, 각 브라켓은 독립 SEO 페이지가 된다. TierMaker가 광고·마케팅 없이 5개월 만에 15만 세션을 달성한 것과 같은 플라이휠이 작동한다.

---

## 차별점 (What Makes This Different)

| 요소 | BracketFights | TierMaker | Save One Drop One |
|------|--------------|-----------|-------------------|
| 브라켓 토너먼트 포맷 | ✓ | ✗ | ✓ |
| 방송 최적화 UI (OBS) | ✗ | ✗ | ✓ |
| 결과 이미지 공유 | ✗ | 부분 | ✓ |
| UGC + SEO 플라이휠 | ✗ | ✓ | ✓ |
| 스트리머 타겟 포지셔닝 | ✗ | ✗ | ✓ |

핵심 우위는 세 가지 레이어다:
1. **포맷 우위**: 한국에서 이미 수년간 검증된 포맷 — 서구 시장에서 재발명이 아니라 수출
2. **채널 우위**: TierMaker를 쓰는 스트리머들이 이미 니즈를 증명했고, 전환 이유가 명확함
3. **플라이휠**: 스트리머 → 시청자 → UGC → SEO → 신규 유저 루프가 한번 돌기 시작하면 복리로 작동

---

## 초기 투자 논리 (Why This Can Win)

Save One Drop One의 핵심 투자 논리는 "브라켓 기능"이 아니라 "방송 가능한 취향 논쟁 포맷의 패키징"이다. TierMaker와 BracketFights는 도구를 제공하지만, Save One Drop One은 스트리머가 바로 방송에 올릴 수 있는 콘텐츠 단위를 제공한다.

초기 wedge는 넓은 팬덤 전체가 아니라, 공유와 논쟁이 이미 강한 카테고리에서 시작한다. K-팝과 애니는 bias, 최애, 캐릭터 순위, 커플링, 세대별 논쟁처럼 1v1 선택 포맷과 자연스럽게 맞는 문화적 행동이 이미 존재한다. MVP 큐레이션은 이 두 카테고리를 우선순위로 두고, 게임·스포츠는 확장 카테고리로 검증한다.

방어력은 단일 기능에서 나오지 않는다. OBS 레이아웃, 결과 이미지, 비교 화면, UGC 생성, SEO 페이지는 각각 복제 가능하지만, 이들이 하나의 루프로 연결되면 콘텐츠 그래프가 된다. 스트리머별 결과 페이지, 시청자 재플레이, 비교 링크, 공개 브라켓 페이지가 쌓일수록 플랫폼 내부의 발견성과 외부 검색 유입이 함께 강화된다.

따라서 초기 검증 질문은 "광고 매출이 바로 나는가?"가 아니라 다음 세 가지다:

1. 스트리머가 같은 도구를 2회 이상 방송에 사용하는가?
2. 한 번의 방송이 의미 있는 시청자 플레이 세션을 파생시키는가?
3. 시청자 결과 공유와 비교 화면이 재방문을 만드는가?

이 세 가지가 검증되면 광고, 프리미엄 creator tools, 브랜드/event 브라켓, rev-share는 트래픽 위에 얹히는 수익화 레이어가 된다.

## 대상 사용자 (Who This Serves)

**1차: 스트리머** (Twitch/YouTube, 구독자 10K~500K)
현재 TierMaker를 방송에 활용하는 미드티어 크리에이터. 콘텐츠 아이디어가 항상 필요하고, 시청자 참여도에 민감하며, 도구 전환 비용이 낮다. "이거 방송하면 채팅이 살아난다"는 경험 하나로 채택된다.

**2차: 팬덤 시청자** (게임·애니·K-팝·스포츠 팬)
스트리머 방송을 보고 직접 해보고 싶어지는 사람. 결과를 Reddit, X(트위터), Discord에 올리며 2차 트래픽을 만든다. "내 결과 봐봐 — 네 생각은?"

**3차: 팬덤 커뮤니티** (r/kpop 200만+, 애니 서브레딧 등)
Save One Drop One 포맷이 이미 K-팝 커뮤니티에서 쓰이고 있음(Quotev, uQuiz). 전용 플랫폼 수요는 검증돼 있고, 커뮤니티 기반 확산 경로도 명확하다.

---

## 사용자별 핵심 Job-to-be-Done

Save One Drop One의 MVP는 기능 목록이 아니라 네 가지 사용자 job을 중심으로 설계되어야 한다.

**1. 스트리머: "오늘 방송할 콘텐츠를 바로 실행하고 싶다"**
- 핵심 요구: 빈 도구가 아니라 방송-ready bracket pack
- 제품 객체: 큐레이션된 브라켓, 썸네일, 제목, 예상 진행 시간, OBS 레이아웃, 공유 링크
- 성공 기준: 스트리머가 별도 준비 없이 10분 이내 방송에 올릴 수 있음

**2. 시청자: "스트리머/친구와 내 취향 차이를 보여주고 싶다"**
- 핵심 요구: 같은 브라켓을 직접 플레이하고 결과를 비교
- 제품 객체: 개인 결과 페이지, 결과 이미지, 비교 링크, side-by-side 결과 화면
- 성공 기준: 방송 후 시청자 플레이와 공유가 자연스럽게 발생

**3. UGC 제작자: "내 팬덤의 대표 브라켓을 만들고 퍼뜨리고 싶다"**
- 핵심 요구: polished bracket creation, attribution, editability, discoverability
- 제품 객체: 제작자명, 공개 브라켓 페이지, 카테고리, 수정 기능, 공유 메타데이터
- 성공 기준: 좋은 UGC가 검색·공유를 통해 반복 플레이를 만든다

**4. 스트리머 모더레이터/커뮤니티 관리자: "방송에 올려도 안전한 콘텐츠인지 확인하고 싶다"**
- 핵심 요구: 오픈 UGC와 방송-safe 큐레이션의 구분
- 제품 객체: curated badge, preview mode, report/takedown, 공개/비공개 상태
- 성공 기준: 스트리머가 라이브 중 위험 콘텐츠 노출 걱정 없이 사용할 수 있음

---

## 핵심 제품 객체: Bracket Pack

MVP의 기본 단위는 단순한 브라켓이 아니라 **Bracket Pack**이다. Bracket Pack은 스트리머가 바로 방송에 사용할 수 있고, 시청자가 방송 후 같은 경험을 재생산할 수 있는 콘텐츠 패키지다.

각 Bracket Pack은 최소한 다음 요소를 가진다:
- 제목
- 카테고리
- 썸네일/대표 이미지
- 참가 항목 목록
- 예상 진행 시간
- OBS-friendly 플레이 레이아웃
- 공개 브라켓 페이지
- 결과 페이지
- 결과 이미지 내보내기
- 비교 링크
- 공유 메타데이터

Bracket Pack은 두 종류로 구분된다:
- **Curated Pack**: 플랫폼이 방송-safe 기준으로 선별한 초기 콘텐츠
- **UGC Pack**: 사용자가 생성한 콘텐츠. 공개 인덱싱 전 최소 품질·정책 기준을 적용한다

---

## 초기 성장 전략 (Go-to-Market)

스트리머 채택이 모든 것의 시작이다. 초기 획득 채널은 세 가지다:

1. **K-팝·애니 중심 직접 DM 아웃리치** — TierMaker 또는 유사 랭킹 콘텐츠를 이미 방송에 활용하는 K-팝·애니 스트리머를 우선 타겟으로 한다. 전환 이유는 "새 도구"가 아니라 "오늘 바로 돌릴 수 있는 방송-ready bracket pack"으로 제시한다.
2. **Reddit/Discord 커뮤니티 공략** — K-팝·애니 서브레딧과 팬 Discord에서 초기 Bracket Pack을 콘텐츠로 배포하고, r/Twitch/r/StreamersConnect는 스트리머 획득 보조 채널로 활용한다.
3. **Twitch Extensions 등록** — 방송 중 라이브 폴 연동을 공식 채널로 추진하되, v1 출시는 OBS 브라우저 소스만으로 가능한 워크플로우를 기준으로 한다.

*이 채널들의 우선순위와 실행 계획은 별도 GTM 리서치를 통해 구체화 예정.*

## 성공 기준 (Success Criteria)

**단기 (0~6개월)**
- TierMaker 또는 유사 랭킹 콘텐츠를 이미 방송에 활용하는 스트리머 3명 이상이 Save One Drop One을 2회 이상 반복 사용
- 스트리머가 Bracket Pack을 선택해 10분 이내 OBS 방송에 올릴 수 있음
- 단일 스트리머 방송에서 파생된 시청자 플레이 세션 1,000회 이상 (바이럴 루프 첫 검증)
- 초기 K-팝·애니 Bracket Pack 중 10개 이상이 방송 또는 커뮤니티 공유를 통해 의미 있는 플레이 세션을 생성

**중기 (6~12개월)**
- 월 세션 50만 이상 달성 (광고 수익 의미 있는 구간 진입)
- UGC 브라켓 500개 이상 누적 (SEO 플라이휠 가동)

**비즈니스 목표**
- 광고: 세션당 ~4 PV × 미국 엔터테인먼트 CPM $3~11 → 규모화 시 주요 수익원
- 중장기: 크리에이터 프리미엄 구독 도구 출시

## 핵심 리스크와 완화 전략 (Key Risks & Mitigations)

Save One Drop One의 가장 큰 리스크는 제품 구현 자체보다 반복 사용 루프 검증이다. 스트리머가 한 번 써보는 것과 정기 방송 포맷으로 채택하는 것은 다르다. 따라서 MVP는 단순한 브라켓 생성기가 아니라, 스트리머가 바로 방송에 올릴 수 있는 "방송-ready 콘텐츠 패키지"로 설계되어야 한다.

**1. 스트리머 채택 리스크**
- 리스크: TierMaker 사용자는 이미 익숙한 워크플로우가 있고, 새 도구 전환 동기가 약할 수 있다.
- 완화: 초기 큐레이션 브라켓은 썸네일, 제목, 예상 진행 시간, OBS 레이아웃까지 포함한 방송용 패키지로 제공한다.
- 검증 기준: 3명 이상의 스트리머가 1회 사용이 아니라 2회 이상 반복 사용.

**2. Twitch Extension 의존 리스크**
- 리스크: Twitch Extension 개발·심사·연동 복잡도가 MVP 출시를 지연시킬 수 있다.
- 완화: v1은 OBS 브라우저 소스 호환 레이아웃을 필수로 제공하고, Twitch Extension 라이브 폴은 v1.5로 병렬 추진한다.
- 검증 기준: Extension 없이도 스트리머가 방송에서 진행 가능한 최소 워크플로우 확보.

**3. UGC/IP/모더레이션 리스크**
- 리스크: 이미지 저작권, NSFW 콘텐츠, 저품질 중복 브라켓이 UGC/SEO 플라이휠을 오염시킬 수 있다.
- 완화: 신고 기능, 관리자 takedown, 공개/비공개 상태, 기본 카테고리 분류, 중복 브라켓 감지 기준을 MVP 운영 요구사항에 포함한다.
- 검증 기준: UGC 생성은 열어두되, 공개 인덱싱은 최소 품질·정책 기준을 통과한 브라켓에 우선 적용.

**4. SEO 플라이휠 리스크**
- 리스크: UGC 페이지가 많아도 검색 노출이 발생하지 않으면 성장 루프가 작동하지 않는다.
- 완화: 각 공개 브라켓 페이지는 고유 title/description, category taxonomy, Open Graph 이미지, 결과 공유 URL, canonical URL을 가진다.
- 검증 기준: 초기 100개 큐레이션 브라켓이 검색·공유 가능한 독립 랜딩 페이지로 작동.

**5. 수익화 타이밍 리스크**
- 리스크: 광고 수익은 트래픽 규모와 광고 차단률에 크게 의존하므로 초기 검증 지표로 부적합할 수 있다.
- 완화: 초기 6개월은 매출보다 반복 사용, 파생 플레이 세션, 공유율, UGC 생성률을 핵심 지표로 본다.
- 검증 기준: 월 50만 세션 이전까지는 광고 매출보다 creator activation과 viral loop 지표를 우선한다.

## 비전 (Vision)

2~3년 후 Save One Drop One은 인터넷의 "VS 문화" 허브가 된다. 누가 최고인지, 무엇이 더 나은지, 내 취향이 남과 어떻게 다른지를 논쟁하고 싶을 때 찾는 곳. 스트리머들의 기본 도구로 자리잡고, IP 홀더들이 팬 참여를 위해 브랜드 브라켓을 의뢰하며, 팬덤 커뮤니티마다 시즌별 토너먼트가 열린다. Discord 봇으로 커뮤니티 서버 안에서 직접 토너먼트가 진행되고, 매주 하나의 Featured Bracket이 전 세계 팬덤의 집단 취향을 기록하는 문화적 이벤트가 된다. 스트리머들이 자신의 브라켓 광고 수익의 일부를 수취하는 크리에이터 수익화 모델도 탐색 대상이다 — 플랫폼 성장에 기여한 창작자에게 경제적 인센티브가 돌아가는 구조는 채택 동기를 한 단계 강화할 수 있다.

"Hot Ones"가 인터뷰 포맷을 재발명했듯, Save One Drop One은 취향 논쟁 포맷의 글로벌 표준이 된다.
