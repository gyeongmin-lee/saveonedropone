**Date:** 2026-05-06

## Executive Summary

Save One Drop One은 한국에서 검증된 이상형 월드컵 포맷을 서구권 스트리머 시장에 맞게 재해석하는 제품 기회를 노린다. 핵심 전제는 단순하다. 1v1 선택 포맷은 이미 팬덤 참여, 스트리머 리액션, 긴 세션 시간, 결과 공유, 검색 유입을 만들어내는 방식으로 검증됐다. 서구권에는 March Madness식 브라켓 문화가 있지만, 엔터테인먼트 팬덤과 스트리머 방송 워크플로우에 최적화된 1v1 브라켓 제품은 아직 뚜렷하지 않다.

PIKU는 직접 경쟁자라기보다 검증된 원형이다. 한국어 팬덤에서 이상형 월드컵은 이미 문화어가 되었고, PIKU는 아이돌, 애니, 게임, 스트리머/BJ, 버튜버 같은 팬덤 소재가 어떻게 토너먼트 UGC로 축적되는지 보여준다. Save One Drop One의 기회는 PIKU를 그대로 복제하는 것이 아니라, 서구권 스트리머가 방송에서 바로 쓸 수 있는 브라켓 콘텐츠 패키지로 재구성하는 데 있다.

최종 전략 방향은 공격적 성장이다. 공개 브라켓은 기본적으로 index한다. 광고는 Day-one부터 가능하게 설계한다. 스트리머의 방송 사용과 수익화는 명확히 허용한다. 법적/운영 리스크는 출시를 늦추는 이유가 아니라 성장 경로를 막지 않는 최소 가드레일로 다룬다. MVP는 플랫폼별 깊은 API 통합보다 OBS 브라우저 소스와 웹 투표 링크에 집중한다.

**핵심 결론:**

- 시장 진입 순서는 서구권 먼저, 이후 글로벌 확장이다.
- PIKU는 경쟁자보다 원형이다. 한국 이상형 월드컵은 제품 포맷의 검증 근거로 사용한다.
- 직접 경쟁은 약하지만 인접 경쟁은 강하다. TierMaker, BracketFights, Challonge, StreamElements, Streamlabs가 사용자의 시간과 워크플로우를 나눠 가진다.
- Save One Drop One의 차별화는 "브라켓 포맷 + 스트리머 방송 사용 + 팬덤 UGC + SEO 페이지"의 결합이다.
- MVP는 OBS 방송 화면, 관리자 컨트롤러, 웹 투표 링크, 결과 공유, 공개 브라켓 SEO 페이지를 중심으로 둔다.
- 구체 기술 스택은 이 도메인 리서치에서 확정하지 않는다.

## Market Opportunity

### Category Definition

Save One Drop One이 진입하는 영역은 독립적인 "브라켓 SaaS" 시장이라기보다 네 시장의 교차 지점이다.

- 라이브 스트리밍 콘텐츠 포맷
- 팬덤 UGC와 취향 공유
- 검색 가능한 엔터테인먼트 페이지
- 크리에이터 워크플로우 도구

이상형 월드컵 포맷은 한국에서 이미 이 교차 지점을 증명했다. 사용자는 후보 두 개 중 하나를 고르는 단순한 행동만 하면 되지만, 실제 가치는 선택 이유, 팬덤 지식, 스트리머 리액션, 채팅 반응, 결과 공유에서 나온다. 즉 제품의 본질은 토너먼트 UI가 아니라 "선택을 방송 콘텐츠와 검색 자산으로 바꾸는 파이프라인"이다.

### Why West First

서구권에는 March Madness를 통해 브라켓 문법 자체가 익숙하다. 그러나 그 문법은 스포츠 이벤트 중심으로 남아 있고, K-pop, 애니, 게임, 스트리머, 인터넷 밈 같은 엔터테인먼트 팬덤을 위한 실시간 방송 도구로는 충분히 제품화되지 않았다.

TierMaker는 서구권 엔터테인먼트 랭킹 수요를 증명하지만, 핵심 포맷은 tier list다. BracketFights는 1v1 브라켓 문법에 가깝지만 방송 워크플로우와 크리에이터 수익화에 최적화되어 있지 않다. 이 사이가 Save One Drop One의 진입 지점이다.

### PIKU as Proof of Format

PIKU는 한국형 이상형 월드컵의 문화적 기본값이다. PIKU 홈과 개별 월드컵 페이지는 K-pop 아이돌, 배우, 애니 캐릭터, 음식, 버튜버, SOOP/BJ 등 다양한 팬덤 소재가 후보군과 이미지로 재조합되는 방식을 보여준다. 각 월드컵은 시작하기, 랭킹보기, 공유 기능을 통해 개인 선택을 사회적 비교와 재방문으로 연결한다.

문서 1은 PIKU의 공개 공식 지표가 제한적이므로 Website Informer의 글로벌 랭크 약 994K, 일 방문자 약 19.5K 같은 제3자 추정치를 중간 신뢰도로 다뤘다. 병합 문서에서는 이 접근을 따른다. 중요한 것은 정확한 방문자 수 하나가 아니라, PIKU가 단발성 놀이가 아니라 반복 방문형 UGC 허브로 작동한다는 구조적 증거다.

### Growth Drivers

**선택 압박이 토크를 만든다.** 1v1 선택은 스트리머에게 즉석 토크를 강제한다. 왜 골랐는지, 무엇을 버렸는지, 팬덤이 왜 반박하는지 자체가 콘텐츠가 된다.

**팬덤 소재는 이미 준비되어 있다.** K-pop, 애니, 게임, 스포츠, 버튜버, 스트리머 팬덤은 후보명, 이미지, 별칭, 밈, 서사를 이미 갖고 있다. 제품은 새 콘텐츠를 발명하기보다 팬덤 자산을 브라켓으로 재배열하면 된다.

**스트리머에게는 방송 시간 채우기가 핵심 문제다.** 즉시 실행 가능한 1v1 브라켓은 "켜면 1~3시간이 채워지는" 콘텐츠 패키지로 작동한다.

**결과 공유가 자연스럽다.** 사용자는 우승자, 라운드별 탈락, 내 선택 결과를 이미지나 링크로 공유하고 싶어 한다. 이는 SEO와 소셜 확산의 기반이다.

**세션 구조가 광고에 유리하다.** 1v1 라운드가 반복될수록 페이지 전환, 체류 시간, 결과 페이지 방문이 늘어난다. 광고는 Day-one부터 제품 경제성의 일부로 볼 수 있다.

## Competitive Landscape

### Competitive Positioning

직접 경쟁은 약하지만 인접 경쟁은 강하다. Save One Drop One은 "브라켓 사이트" 하나와만 경쟁하지 않는다. 스트리머의 방송 시간, 팬덤의 공유 시간, 검색 유입, 크리에이터 툴체인 안의 화면 공간을 두고 여러 제품과 경쟁한다.

| 플레이어 | 역할 | 강점 | Save One Drop One 관점 |
|---|---|---|---|
| PIKU | 한국 이상형 월드컵 원형 | 한국어 팬덤 밀도, 포맷 검증, 공유/랭킹 습관 | 직접 경쟁보다 참고 모델 |
| TierMaker | 글로벌 tier list 허브 | 템플릿 폭, 검색 유입, 카테고리 인지도 | 강한 인접 경쟁 |
| BracketFights | 1v1 브라켓 인접 제품 | 포맷 유사성, UGC 브라켓 | 방송 최적화와 크리에이터 친화성에서 차별화 가능 |
| Challonge | e스포츠 브라켓 | 실제 대회 운영, 토너먼트 신뢰도 | 사용 목적이 달라 낮은 직접 위협 |
| StreamElements/Streamlabs | 방송 툴체인 | OBS 오버레이, 스트리머 워크플로우 점유 | 통합 대상이자 인접 경쟁 |
| YouTube/Twitch/Kick/Discord | 유통 플랫폼 | 시청자와 커뮤니티 보유 | 플랫폼보다 위에 얹히는 웹 콘텐츠로 접근 |

### Strategic Gap

서구권에는 팬덤 엔터테인먼트 브라켓 수요가 있고, 스트리머에게는 즉시 방송 가능한 콘텐츠 패키지 수요가 있다. 그러나 기존 제품은 한쪽만 충족한다.

- TierMaker는 팬덤 랭킹 수요를 충족하지만 1v1 드라마가 약하다.
- BracketFights는 1v1 브라켓을 제공하지만 방송 UX와 스트리머 수익화 메시지가 약하다.
- 스트리머 툴은 OBS 오버레이와 후원/알림에는 강하지만 브라켓 콘텐츠 자체를 제공하지 않는다.
- PIKU는 포맷을 증명했지만 한국어 문화권 원형에 가깝다.

Save One Drop One의 포지션은 이 공백에 들어간다.

> 서구권 스트리머가 바로 방송에 올릴 수 있는 팬덤 1v1 브라켓 콘텐츠 플랫폼.

### Differentiation

**Creator-friendly use.** 스트리머가 방송에서 자유롭게 사용할 수 있음을 명확히 한다. 사용자가 방송 수익을 얻는다는 이유만으로 불안해하지 않게 하는 것이 직접 전환 이유가 된다.

**Broadcast-first workflow.** 일반 사용자의 플레이 URL과 스트리머의 방송 URL, 관리자 컨트롤러, 웹 투표 링크, 결과 공유 URL을 분리한다.

**Public bracket SEO.** 공개 브라켓은 기본 index한다. 각 브라켓은 독립적인 검색/공유 자산이다.

**Fan templates as content inventory.** 초기에는 큐레이션된 팬덤 브라켓 라이브러리를 확보해야 한다. 기술보다 초기 콘텐츠 밀도와 카테고리 선택이 중요하다.

**PIKU-like simplicity, Western streamer packaging.** 화면 규칙은 단순해야 한다. 제품 패키징은 스트리머가 바로 쓸 수 있어야 한다.

## UGC and SEO Growth Strategy

### SEO Principle

이 병합본의 SEO 전략은 성장 우선이다. 모든 공개 브라켓은 기본적으로 index한다. 검색 노출은 제품 성장의 핵심 엔진이며, UGC 브라켓은 롱테일 키워드를 자연스럽게 생성한다.

단, "공개"와 "비공개/초안"은 분리한다. 사용자가 공개한 브라켓은 검색 가능한 자산으로 취급하고, 초안·개인 링크·명백한 고위험 콘텐츠만 제한한다.

### Indexable Page Types

- 공개 브라켓 랜딩 페이지
- 브라켓 결과 페이지
- 우승자/랭킹 페이지
- 카테고리별 브라켓 모음
- 스트리머가 사용한 방송 결과 페이지
- 팬덤별 인기 브라켓 페이지
- 결과 공유 이미지가 포함된 소셜 미리보기 페이지

### SEO Flywheel

1. 팬덤 주제 브라켓 생성
2. 스트리머가 방송에서 사용
3. 시청자가 웹 투표와 결과 공유에 참여
4. 공개 브라켓과 결과 페이지가 검색에 노출
5. 검색 유입 사용자가 새 브라켓을 만들거나 기존 브라켓을 재사용
6. 인기 브라켓이 다시 방송 소재가 됨

이 루프에서 중요한 것은 브라켓 수 자체다. 후보 메타데이터, 결과 페이지, 공유 이미지, 댓글/토론은 품질 신호를 강화하지만, 초기 성장은 공개 페이지의 양과 팬덤 키워드 커버리지에서 나온다.

### Content Quality Without Slowing Growth

성장을 막는 사전 검수는 MVP 기본값이 아니다. 대신 다음과 같은 가벼운 제한을 둔다.

- 명백한 NSFW, 혐오, doxxing, 직접 괴롭힘은 제한
- 신고가 누적된 페이지는 검토
- 고위험 카테고리는 광고 게재나 추천 노출에서만 제한
- 삭제 요청이 들어온 URL은 빠르게 처리

즉, "기본 index + 빠른 대응"이 원칙이다.

## Regulatory and Policy Lens

### Operating Assumption

규제 기준은 미국/글로벌 중심으로 둔다. 다만 이 문서는 법률 검토 문서가 아니라 도메인 리서치다. 제품 전략은 성장 우선이며, 법적 고려는 출시를 늦추는 프레임이 아니라 성장 채널을 열어두는 최소 운영 장치로 다룬다.

### Practical Guardrails

**DMCA 대응.** UGC 플랫폼으로서 신고-삭제 흐름과 반복 침해자 정책은 갖춰야 한다. 이는 성장을 막기 위한 장치가 아니라 광고와 검색을 안정적으로 운영하기 위한 기반이다.

**광고 Day-one.** 광고는 출시 초기부터 가능하다. 다만 명백한 고위험 UGC, 신고 누적 콘텐츠, 민감 카테고리는 광고 제한 대상으로 둘 수 있다.

**스트리머 방송 사용 허용.** Save One Drop One은 크리에이터 친화적 ToS를 가져야 한다. 스트리머가 방송에서 사용하고 방송 수익을 얻는 행위는 기본 허용한다.

**팬덤 IP는 기회 중심.** K-pop, 애니, 게임, 스트리머 팬덤은 제품 성장의 핵심 원료다. 팬덤 콘텐츠 사용은 인터넷 문화의 기본 행동에 가깝고, 과도한 법적 리스크 프레이밍은 제품의 기회를 흐린다. 상업적 브랜드 캠페인이나 공식 권리자 이벤트로 확장할 때만 별도 검토를 강화한다.

**아동/미성년 트래픽.** K-pop, 애니, 게임 카테고리는 미성년 사용자 유입 가능성이 있다. MVP에서는 과도한 데이터 수집을 피하고, 계정/광고/개인화 기능이 커질 때 연령 및 개인정보 흐름을 정교화한다.

### Policy Positioning

Save One Drop One은 BracketFights식 상업적 이용 불안을 만들지 않아야 한다. 핵심 문장은 명확해야 한다.

> 스트리머는 Save One Drop One 브라켓을 방송 콘텐츠로 사용할 수 있으며, 해당 방송에서 발생하는 일반적인 광고, 후원, 구독, 플랫폼 수익을 얻을 수 있다.

이 메시지는 제품 차별화의 일부다.

## Streamer Workflow and Product Implications

### MVP Surface

MVP는 기술 스택이 아니라 사용자 표면으로 정의한다.

- 관리자 컨트롤러
- OBS용 방송 화면 URL
- 웹 투표 링크
- 공개 브라켓 페이지
- 결과 공유 페이지
- 기본 신고/삭제 흐름

플랫폼별 API 통합은 후속 기능이다. 초기에는 Twitch, YouTube, Kick, Discord 등 특정 플랫폼에 깊게 묶이지 않는다. OBS와 웹 링크는 대부분의 방송 환경을 가로지르는 가장 빠른 공통 표면이다.

### Streamer Jobs To Be Done

**방송 전에:** 주제 선택, 후보 확인, 라운드 수 선택, 방송 화면 URL 준비.

**방송 중에:** 다음 매치 진행, 투표 링크 공유, 채팅 반응 유도, 결과 공개, 논쟁 만들기.

**방송 후에:** 결과 링크 공유, 클립/쇼츠 제작, 팬덤 커뮤니티에 결과 게시, 다음 브라켓으로 재방문 유도.

### Product Requirements Implied by Domain

- 스트리머가 5분 안에 방송 가능한 브라켓을 열 수 있어야 한다.
- 후보 이미지는 방송 화면에서 깨지지 않아야 한다.
- 브라켓 진행은 실수하기 어려워야 한다.
- 시청자는 계정 없이 투표에 참여할 수 있어야 한다.
- 결과 페이지는 공유와 검색에 적합해야 한다.
- 공개 브라켓은 기본적으로 검색 노출되어야 한다.
- 스트리머의 상업적 방송 사용은 명확히 허용되어야 한다.

### What Not To Prioritize in MVP

- 특정 플랫폼 Extension
- 깊은 플랫폼 API 의존
- 복잡한 권리자 포털
- 과도한 사전 검수
- AI 자동 생성
- 네이티브 모바일 앱
- 상세 기술 스택 확정

이 기능들은 후속 단계에서 검토할 수 있지만, MVP의 핵심은 방송 가능한 브라켓 콘텐츠와 공개 SEO 페이지를 빠르게 늘리는 것이다.

## Strategic Opportunities

### Opportunity 1: Streamer-ready Bracket Packs

서구권 스트리머가 바로 쓸 수 있는 큐레이션 브라켓 팩을 제공한다. 예시는 K-pop idols, anime characters, game bosses, streamers, VTubers, fast food, movie villains, sports icons 등이다. 초기 콘텐츠 밀도는 제품의 실제 해자다.

### Opportunity 2: Public Bracket SEO Library

모든 공개 브라켓을 검색 가능한 독립 페이지로 운영한다. 팬덤 키워드와 브라켓 제목이 곧 롱테일 SEO 자산이 된다.

### Opportunity 3: Creator-friendly Terms

기존 브라켓 도구가 스트리머 사용과 수익화에 모호하거나 제한적인 경우, Save One Drop One은 명확한 허용 정책으로 차별화한다. 이는 기능보다 강한 전환 메시지가 될 수 있다.

### Opportunity 4: Broadcast Result Sharing

방송 후 결과 페이지를 자동으로 공유 가능한 형태로 만든다. 우승자, 결승 매치, 라운드별 이변, 시청자 투표 결과가 클립과 커뮤니티 게시글의 소재가 된다.

### Opportunity 5: Global Expansion from Western Beachhead

서구권에서 스트리머 워크플로우와 SEO 플라이휠을 검증한 뒤, 언어와 카테고리를 확장한다. 한국 원형은 이미 검증 사례로 남기고, 제품 확장은 영어권 팬덤과 글로벌 스트리머 중심으로 시작한다.

## Future Outlook

### Platform Integrations

초기에는 OBS와 웹 투표 링크에 집중한다. 이후에는 Twitch, YouTube, Kick, Discord 등에서 가능한 채팅/투표/보상 연동을 일반화된 "platform integrations"로 확장한다. 특정 기술이나 API 이름을 MVP 전략에 고정하지 않는다.

### AI Bracket Creation

AI 브라켓 자동 생성은 장기 아이디어다. 사용자가 주제를 입력하면 후보군, 시드, 설명, 이미지 후보를 제안하는 흐름은 강력하지만, MVP의 핵심은 아니다. 초기에는 큐레이션된 브라켓과 UGC 생성 루프가 더 중요하다.

### Fan Community CMS

장기적으로 Save One Drop One은 단일 브라켓 툴을 넘어 팬덤 이벤트 CMS가 될 수 있다. 같은 후보 데이터를 1v1 브라켓, tier list, quiz, live poll, Discord 이벤트, 방송 결과 페이지로 재사용할 수 있다.

### Official Campaigns

제품이 성장하면 권리자, 브랜드, 이벤트 주최자와 공식 브라켓 캠페인을 운영할 수 있다. 이 단계에서는 라이선스와 브랜드 세이프티가 중요해지지만, 초기 성장 전략을 제약하는 기준으로 삼지는 않는다.

## Product Implications for PRD

PRD 작성 시 다음 방향을 반영한다.

1. Save One Drop One은 서구권 스트리머 시장을 1차 타깃으로 한다.
2. PIKU는 검증된 한국 원형으로 사용하고, 직접 경쟁자로 과도하게 다루지 않는다.
3. 공개 브라켓은 기본 index한다.
4. 광고는 Day-one부터 가능한 수익 모델로 둔다.
5. 스트리머 방송 사용과 일반적 방송 수익화는 명시적으로 허용한다.
6. MVP는 OBS 방송 화면과 웹 투표 링크 중심이다.
7. 플랫폼 API와 Extension은 후속 기능이다.
8. 기술 스택은 PRD/아키텍처 단계에서 별도 결정한다.
9. 팬덤 IP는 성장 기회로 다루고, 과도한 법적 경고 톤을 피한다.
10. 초기 해자는 코드보다 큐레이션 브라켓 라이브러리, 검색 페이지, 스트리머 사용 사례다.

## Research Conclusion

Save One Drop One의 기회는 한국 이상형 월드컵 포맷을 서구권 스트리머 시장에 맞게 제품화하는 데 있다. 포맷은 이미 검증됐다. 직접 경쟁은 약하다. 인접 경쟁은 강하지만, 그만큼 수요도 명확하다.

제품은 PIKU처럼 단순해야 하고, TierMaker처럼 검색 자산을 쌓아야 하며, StreamElements/Streamlabs처럼 방송 워크플로우에 자연스럽게 들어가야 한다. 그러나 최종 포지션은 그 어느 하나의 복제가 아니다.

Save One Drop One은 스트리머가 방송에서 바로 쓰고, 시청자가 투표하고, 팬덤이 결과를 공유하고, 공개 브라켓이 검색에 쌓이는 성장형 팬덤 브라켓 플랫폼으로 정의한다.
